# Políticas del flujo inline

- [Trabajo](work.md): resultado, autonomía, delegación y finalización.
- [Evidencia](evidence.md): comprobaciones pertinentes y registros opcionales para integraciones.
- [Entrega](delivery.md): autorización, seguridad de ramas y evidencia de entrega.

El principal no exige envelopes ni transferencias de rol. El catálogo selecciona estas políticas para el flujo actual. Los registros manuales no sustituyen observaciones reales ni permisos del usuario o del host.
